## 🚀 Featured Flagship Project

### 🏋️ [PulseFit AI – RAG-Powered Fitness Intelligence & Workout Copilot](https://joelaah.github.io/fitness_app/)
**[🌐 Live Web Application](https://joelaah.github.io/fitness_app/)** | **[📱 Frontend Repo](https://github.com/joelaah/fitness_app)** | **[⚡ RAG Backend Repo](https://github.com/joelaah/fitness-rag-api)**

- **Two-Stage RAG Pipeline**: Qdrant Cloud HNSW vector recall (768-dim embeddings via Google GenAI gemini-embedding-2) + Cohere Cross-Encoder (
erank-v3.5) reranking to achieve 94%+ retrieval precision.
- **Deterministic Guardrails**: Python math layer calculating volume progression and push/pull split ratios to prevent LLM hallucinations.
- **Flutter Web Client**: Responsive CanvasKit-accelerated interface with real-time set/rep logging, volume analytics, and local offline fallbacks.
